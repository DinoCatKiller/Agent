## 内部布局（`D6` §3，按需创建，不预建空文件）

```
src/
  lib.rs        模块声明 + 对外导出
  chat.rs       领域类型：Chat（模型 id + 消息序列 + 当前流状态）
  service.rs    业务编排：发起、增量累积、取消、截断与错误后的状态回滚
  repo.rs       本功能自己的持久化（调 kernel/store 的连接与事务）—— 需要时再建
  ui.rs         本功能的界面 —— 等 D3 定了再建
tests/          本功能的测试与 fixtures（状态机可纯数据驱动，不需要网络 —— Q1）
docs/           本功能的规格（A5 工具调用、A7 上下文与 Token）
```

## 为什么是"一个文件夹"

按 `D5` + `D6`：**一个功能 = 一个文件夹**。加一个对话能力（"图片输入"、"停止生成"、"重新生成"）时，
改动应该只落在本目录里 —— 业务编排、状态、界面、测试、fixtures 都在这里。
