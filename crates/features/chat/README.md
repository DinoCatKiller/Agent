## 为什么是"一个文件夹"

按 `D5`：**一个功能 = 一个文件夹**。加一个对话能力（比如"图片输入"、"停止生成"、"重新生成"）时，
改动应该只落在本目录里 —— 业务编排、状态、界面、测试、fixtures 都在这里。
