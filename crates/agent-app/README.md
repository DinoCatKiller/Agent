## 现在能做什么

```powershell
cargo run -p agent-app -- self-check
```

打印 7 段，用于证明契约层可用：

1. 消息模型（构造器 + `text()`）
2. 请求序列化（含工具定义与 `response_format`）
3. **能力协商 fast-fail**：只有 `JsonMode` 的模型请求严格 schema 输出时必须被拒（内含 assert）
4. 流式事件序列 + 无状态拼接
5. 工具结果回填
6. 错误分类与可重试判定
7. 供应商注册表（当前为空）

不带参数运行会打印版本与可用命令。

## 它不能做什么

- ❌ 不联网：没有 HTTP、SSE、真实模型调用
- ❌ 没有 UI、存储、配置与密钥、Agent 循环、路由
