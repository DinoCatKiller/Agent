## TL;DR

- **密钥**：只存在于系统钥匙串 / 环境变量 / CLI 参数；**绝不入库、绝不进日志、绝不进 `Debug` 输出**（细节见 `R1` §4，本节不复制）。
- **本地优先**：会话历史与配置留在本机；本应用**不自动上传任何数据**（`G1` §1.1）。
- **出网只有一条路**：用户显式配置的模型 endpoint（HTTPS + rustls）；最多再加一个用户自配的代理。
- **MCP server 是本机子进程**，等价于「用户自己运行的程序」。本应用**不沙箱**它 —— 可信边界在用户（`D8` 遗留，见 §4）。
- **审计只记元数据**：谁在何时调了哪个模型、用了多少 token；**不记对话内容**。

## 1. 密钥

红线与实现全在 `R1` §4：钥匙串存储、配置文件禁放、错误信息不回显、明文只在装配边界短暂存在。

本节的补充只有一条：**新增任何「配置来源」时都必须过同一套红线**（例如将来加 GUI 设置面板，写钥匙串要复用 `agent-config`，不能另起一套明文存储）。

## 2. 数据与隐私

| 数据 | 位置 | 出网 |
|------|------|------|
| 会话历史 | 本地 SQLite（`kernel/store` → `features/chat/repo`） | ❌ |
| 配置（非敏感） | 平台标准目录的 TOML（`R1`） | ❌ |
| 密钥 | 系统钥匙串（`R1`） | ❌ |
| 对话内容 | 仅在**调用模型时**发给用户配置的 endpoint | ✅（用户显式配置） |

- **不发遥测**：崩溃报告、使用统计一律不做（`R3` §4）。
- **日志不记内容**：只记长度 / 条数 / 模型 / token 数这类元数据（`R3` §1）。prompt 全文可能含隐私，禁止落日志。

## 3. 网络

- 全部走 `reqwest` + **rustls**（无 OpenSSL 依赖，见 `X1` §1）；不允许明文 HTTP（用户配 `http://` 的本地端点属自担风险，UI 应提示）。
- 代理由用户显式配置（`R1` 的 `proxy`）；**不自动读系统代理**（避免把流量导去用户没预期的地方）。
- 超时与空闲超时是**安全**手段而非仅仅是体验（防止挂死连接），默认值见 `A4`。

## 4. 工具与 MCP 的可信边界

| 来源 | 可信度 | 说明 |
|------|--------|------|
| 内置 Rust 工具（`A5` 的 `Tool` trait） | **可信** | 本仓库代码，随二进制分发（如 `current_time` / `echo`） |
| MCP server（`D8`） | **用户自担** | 本机子进程（stdio），等于用户自己装的程序 |

红线（`D8` 遗留、本节明确）：

1. **不自动启动**：MCP server 必须由用户显式配置（`R1` 的配置来源）才会被拉起；不允许「扫目录自动发现并运行」。
2. **不继承敏感环境变量**：spawn 子进程时**过滤掉** `*_API_KEY` / `*_TOKEN` 这类变量 —— 否则一个第三方 server 就能白拿用户的密钥。
3. **工具的副作用由用户判断**：本应用不会自动批准工具调用（当前是「模型要求 + 宿主执行」），将来加「自动批准」必须带**按工具的白名单**，不能全局放开。
4. **输出按不可信处理**：MCP 返回的内容只作为 `tool_result` 回传模型，不当作指令执行（防 prompt 注入扩散）。

## 5. 审计

- 记什么：`timestamp` / `provider` / `model` / `tokens` / `cost` / `outcome`（就是 `R3` §2 的 span 字段）。
- 不记什么：prompt 与回复正文、密钥、文件内容。
- 落点：`tracing` 一条线（`R3`），需要长期留存时由宿主决定是否落文件；**本轮不做专用审计表**（避免为小需求养一张表）。
